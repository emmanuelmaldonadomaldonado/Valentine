## 🌹 About The Project

A modern, interactive, and fully animated web application designed to ask that special someone to be your Valentine. It features a beautifully crafted **Envelope** opening animation, a sleek **Glassmorphism** UI, and playful interactions.

### ✨ Features

-   **💌 Interactive Envelope**: A realistic opening animation using CSS clips and Framer Motion.
-   **🔮 Glassmorphism UI**: Premium frosted glass aesthetic with depth and blurs.
-   **✨ Dynamic Background**: Floating particles/hearts that create a lively atmosphere.
-   **😈 "No Choice" Logic**: The "No" button playfull runs away or disappears if they persist!
-   **📱 Mobile Optimized**: Carefully tuned to look perfect on phones and desktops.
-   **📸 Personal Touch**: Integrates your own photo for a truly personal proposal.

## 🚀 How to Run Locally

1.  **Clone the repo**
    ```sh
    git clone https://github.com/your_username/valentine-app.git
    ```
2.  **Install dependencies**
    ```sh
    npm install
    ```
3.  **Start the server**
    ```sh
    npm run dev
    ```

## 🌍 Deployment

This project is optimized for deployment on **Vercel**.

1.  Run `npx vercel` in your terminal.
2.  Follow the prompts.
3.  Share the link! 💌
